# Make Automation Calculator — Zapier to Make.com Savings Calculator

Free calculator: compare your current Zapier bill to Make.com and see how much you'd save switching.

## Run Locally

**Prerequisites:** Node.js

1. Install dependencies: `npm install`
2. Run the app: `npm run dev`
